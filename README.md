# Flutter Practice Projects

This repository contains the source code for 13 Flutter practice projects, designed to help learners understand the fundamentals of Flutter and gradually build mobile application development skills through hands-on exercises.

## Practice Projects

1. **Hello World** – Introduction to the basic structure of a Flutter application.
2. **Classroom** – Build a simple static user interface.
3. **Layout** – Practice building layouts using widgets such as Row, Column, and Stack.
4. **My Page** – Create a personal profile screen.
5. **Change Color** – Learn basic state management by changing UI colors.
6. **Counter** – Build a counter application using `setState`.
7. **Login & Profile** – Design login and user profile screens.
8. **Register** – Create a registration form with input validation.
9. **BMI Calculator** – Develop a simple BMI calculator using Flutter widgets and logic.
10. **Feedback** – Design a feedback form.
11. **My Place** – Display a list of featured places.
12. **Product** – Build product list and product detail interfaces.
13. **News** – Create a news listing interface.

## Technologies

- Flutter
- Dart
- Material Design

## Getting Started

1. Install the Flutter SDK.
2. Clone this repository.
3. Open the project folder that contains the `pubspec.yaml` file.

```bash
cd 13BaiTapFlutter-master/menu_project
```

4. Install dependencies.

```bash
flutter pub get
```

5. Run the application.

```bash
flutter run
```
